# 3D μοντέλα

- **Michelle.glb**: χαρακτήρας από το [Mixamo](https://www.mixamo.com) (Adobe), όπως διανέμεται στα examples του [three.js](https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf). Οι χαρακτήρες Mixamo επιτρέπεται να χρησιμοποιούνται royalty-free μέσα σε έργα (προσωπικά/εμπορικά). Δεν επιτρέπεται η αναδιανομή τους ως αυτόνομα assets.
- Ο coach οδηγείται από τον κώδικα (`js/skinned.js`): οποιοδήποτε `.glb` με σκελετό τύπου Mixamo μπορεί να μπει στη θέση του από τις Ρυθμίσεις → 3D Coach.
