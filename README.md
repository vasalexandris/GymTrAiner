# GymTrAIner 🏋️
Προσωπικός AI γυμναστής, διατροφολόγος και coach που τρέχει ολόκληρος στον browser (στατική εφαρμογή για GitHub Pages) με **Google Gemini** και **YouTube Data API**.

## Τι κάνει
- **Γνωριμία**: ερωτηματολόγιο (σώμα, τραυματισμοί, εξοπλισμός, διατροφή, ύπνος, διάθεση).
- **Εκτίμηση & στόχοι**: ο AI αναλύει την κατάσταση και προτείνει στόχους.
- **Πρόγραμμα γυμναστικής** προσαρμοσμένο σε τραυματισμούς/εξοπλισμό, με οδηγίες, συχνά λάθη, εναλλακτικές, βίντεο YouTube και μουσική ανά άσκηση.
- **3D Coach (three.js) με φωνή**: ένας avatar εκτελεί την άσκηση μπροστά σου, μετράει τις επαναλήψεις φωναχτά (Web Speech API, ελληνικά), δίνει οδηγίες, χρονίζει σετ/ξεκούραση και σε παροτρύνει. Παύση, παράλειψη, επιλογή ρυθμού, wake-lock οθόνης.
- **Εναλλακτική άσκηση** με ένα κλικ (με προαιρετικό λόγο, π.χ. «δεν έχω ιμάντες»)· ο coach θυμάται τι αποφεύγεις.
- **Μουσική**: δηλώνεις είδη/καλλιτέχνες και κάθε άσκηση προτείνει αντίστοιχη μουσική (YouTube).
- **Εβδομαδιαίο πρόγραμμα διατροφής** + λίστα αγορών.
- **Πρόοδος**: εβδομαδιαίο check-in, γράφημα βάρους, αξιολόγηση και αυτόματη προσαρμογή προγραμμάτων.
- **Ιατρικές εξετάσεις**: PDF/φωτογραφία/κείμενο → περίληψη και επιπτώσεις σε προπόνηση/διατροφή.
- **Coach chat** με πλήρες context.

## Προβολή άσκησης
- **🎬 Βίντεο (προεπιλογή)**: σύντομο βίντεο επίδειξης από το YouTube σε loop, βουβό, ενώ ο coach μετράει/μιλάει από πάνω. Το «↻ Άλλο βίντεο» αλλάζει επίδειξη και η επιλογή αποθηκεύεται ανά άσκηση.
- **🧍 3D coach**: εναλλακτική προβολή με avatar (δες παρακάτω).

## 3D coach
- Ρεαλιστικό μοντέλο με σκελετό (Michelle, Mixamo) που κινείται με retargeting από τη βιβλιοθήκη κινήσεων (`js/motions.js` → `js/avatar.js` → `js/skinned.js`).
- Εξοπλισμός ανά άσκηση: αλτήρες, kettlebell, λάστιχα, ιμάντες TRX, μπάρα, στρώμα (`js/equipment.js`) — τα δάχτυλα κλείνουν στη λαβή.
- Μπορείς να ανεβάσεις δικό σου (π.χ. φωτορεαλιστικό) μοντέλο Mixamo `.glb` από τις Ρυθμίσεις.

## Περιορισμοί του 3D coach
Ο avatar χρησιμοποιεί βιβλιοθήκη ~15 βασικών κινήσεων (`js/motions.js`)· το AI διαλέγει ποια ταιριάζει σε κάθε άσκηση (ή γίνεται αναγνώριση από το όνομα). Για ασκήσεις εκτός βιβλιοθήκης δείχνει γενική κίνηση — το βίντεο YouTube παραμένει η αναφορά για την ακριβή εκτέλεση.

## Ιδιωτικότητα
Δεν υπάρχει server. Τα δεδομένα και τα API keys μένουν στο `localStorage` και τα κλήσεις γίνονται απευθείας προς Google. Χρησιμοποίησε keys με περιορισμό **HTTP referrer** στο domain σου.

## Τρέξιμο
Τοπικά: `python3 -m http.server 8000` και άνοιξε http://localhost:8000.
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root. Μετά άνοιξε Ρυθμίσεις και βάλε τα keys.
